# Evaluator Guide

Orbit Sales OS was designed to be easy to review in a short session without setup friction.

## Fastest Review Path

1. Run `npm install`
2. Run `npm run dev`
3. Open the local app URL
4. Start on the login screen and enter as `Executive Leadership`

## Suggested Role Walkthrough

- `Executive Leadership`
  - Best for reviewing high-level KPIs, forecasts, regional performance, and strategic views
- `Sales Manager`
  - Best for team metrics, discount approvals, territory ownership, and sales performance oversight
- `Account Manager`
  - Best for customer history, relationship health, renewal planning, and account-level context
- `Marketing Team`
  - Best for campaign ROI, lead-sharing, and segment-driven analysis
- `Product Manager`
  - Best for feature requests, documentation coverage, and customer feedback capture

## Recommended Pages To Open

- `Dashboard`
  - KPI cards, trend lines, funnel view, regional comparison, and forecast widgets
- `Customers`
  - Profiles, interaction history, satisfaction, and renewal data
- `Pipeline`
  - Opportunity values, stages, probabilities, and owner assignments
- `Activities`
  - Calls, meetings, notes, and follow-up visibility
- `Team`
  - Leaderboards, territory management, and discount workflow
- `Reports`
  - Revenue trend analysis, win/loss, and regional planning views
- `Marketing`
  - Campaign performance and lead sharing
- `Product`
  - Product updates, documentation, feedback, and feature requests
- `Executive`
  - Strategy-facing business overview

## Bonus Details Worth Noticing

- Theme presets for different dashboard moods without breaking readability
- Persistent local data so changes survive refreshes
- Route-level SEO metadata and polished login presentation
- Idle timeout and error boundary support for a more production-like frontend
- Frontend audit logs and sanitized markdown rendering
- In-app evaluator quick tour card on the dashboard
